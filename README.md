
# ATmega328P CDI Ignition Controller

### Embedded Hardware & PCB Design | EasyEDA

A custom Capacitor Discharge Ignition (CDI) controller PCB designed around the ATmega328P AVR microcontroller using EasyEDA.

The project integrates high-voltage capacitor charging, VR pickup signal conditioning, ignition coil triggering, and embedded control circuitry into a compact PCB for engine ignition applications.

This repository showcases PCB layout, component placement, power distribution, signal routing, and the integration of high-voltage and low-voltage circuitry.

---

## Project Highlights

- ATmega328P 8-bit AVR microcontroller
- High-voltage capacitor charging circuitry
- VR pickup signal conditioning interface
- Ignition coil triggering circuitry
- USB interface for embedded development
- AVR ISP programming header
- Dedicated high-voltage and logic circuit regions
- Power regulation and protection components
- PCB routing with attention to electrical isolation
- Compact PCB architecture for engine-control applications

## Engineering Considerations

The PCB design incorporates dedicated high-voltage and logic circuit regions, with attention to component placement, signal routing, power distribution, and electrical isolation.

The ATmega328P controller interfaces with the VR pickup signal-conditioning circuit and ignition-triggering stage.

The high-voltage charging section and ignition coil output are integrated alongside the embedded control circuitry.

The board also provides interfaces for embedded firmware programming and hardware debugging.
